## 📌 Project Overview

The Global Store Dashboard is a business intelligence project developed using Microsoft Power BI. It presents business data through interactive visualizations to help users explore sales performance and identify meaningful patterns.

The project demonstrates practical skills in dashboard development, data visualization, and business analytics.

## 🎯 Project Objectives

- Transform business data into meaningful visual insights.
- Explore sales performance and business trends.
- Present information through interactive reports.
- Develop practical Power BI and business intelligence skills.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Microsoft Power BI Desktop | Dashboard development |
| Power Query | Data preparation and transformation |
| DAX | Calculations and measures |
| Microsoft Excel | Data source and spreadsheet analysis |

## 🚀 Getting Started

### Prerequisites

- Microsoft Power BI Desktop
- Windows recommended for Power BI Desktop

### Installation

Clone the repository:

```bash
git clone https://github.com/Ribhu131/Global-Store-Dashboard.git
```

Navigate to the project folder:

```bash
cd Global-Store-Dashboard
```

### Open the Dashboard

1. Locate `global store dashboard.pbix`.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, update the data source path.
4. Refresh the data if the original source is available.
5. Explore the report and its visualizations.
